## 二、商店文案（直接复制）

**名称**：电商图片提取下载

**简短说明**（≤132 字）：

> 在淘宝、京东、拼多多商品详情页一键提取商品图片，勾选后批量下载为 PNG。

**详细说明**：

> 电商图片提取下载是一款面向电商商家与运营人员的 Chrome 扩展，帮助你在淘宝、天猫、京东、拼多多商家版商品详情页快速提取商品图片并批量保存。
>
> 功能特性：
> - 一键提取：打开商品详情页，点击右下角「获取图片」按钮，自动扫描页面（含 iframe）中的商品图
> - 原图还原：自动剥离淘宝/京东/拼多多 CDN 的缩略图尺寸后缀与压缩参数，优先获取原图
> - 智能过滤：自动过滤图标、logo、二维码、占位图等小于 100×100 的无效图片
> - 批量下载：图库页勾选所需图片，一键批量转 PNG 下载（文件名自动编号：商品图_001.png…）
> - 进度可视：下载过程实时显示进度与失败明细，失败自动重试
>
> 使用方法：
> 1. 打开淘宝 / 天猫 / 京东 / 拼多多商家版的商品详情页
> 2. 点击页面右下角「获取图片」按钮（或点击浏览器工具栏的扩展图标）
> 3. 在新打开的图库页勾选图片，点击「下载选中」
> 4. 文件保存到浏览器默认下载目录（可通过浏览器设置改为桌面等位置）
>
> 隐私说明：本扩展不收集、不存储、不传输任何用户数据。提取的图片链接仅保存在浏览器本地存储中用于下载，不上传任何服务器。

**类别**：购物（Shopping）

**语言**：中文（简体）

## 三、隐私声明（数据收集申报）

在商店的「隐私权」页签中，所有数据收集项均选择**「否」**（本扩展无任何网络上报、无统计、无账号）。

如商店要求提供隐私政策链接，可将以下文本发布到任意可访问的 URL（如 GitHub Gist / Pages）后填入：

```text
隐私政策

本扩展（电商图片提取下载）不收集、不存储、不传输任何用户个人信息。
扩展仅在用户主动触发时读取当前商品详情页中的图片地址，并将这些地址
保存在浏览器本地存储（chrome.storage.local）中，仅用于用户自己勾选和
下载图片。数据不离开用户设备，不发送到任何第三方服务器。

更新日期：2026-10-27
```

## 四、Chrome Web Store 发布步骤

1. 注册开发者账号：https://chrome.google.com/webstore/devconsole/register （一次性 $5，需信用卡/借记卡）
2. 进入开发者控制台 → **新增项目**
3. 上传 `dist/ecommerce-image-extractor-v1.0.0.zip`
4. 填写商店商品信息：
   - 名称 / 简短说明 / 详细说明 → 复制上文文案
   - 类别 → 购物；语言 → 中文（简体）
   - 图标 → 上传 `icons/icon128.png`
   - 截图 → 至少 1 张 1280×800 或 640×400
5. 「隐私权」页签：所有数据收集项选「否」，填入隐私政策链接（如需要）
6. 「分发」页签：可见性选择「公开」或「不公开」（未列出，仅凭链接可装）
7. 提交审核 → 通常 1~3 个工作日（首次可能更长）

## 五、Edge Add-ons 发布步骤

1. 打开 https://partner.microsoft.com/dashboard/microsoftedge ，用 Microsoft 账号登录（免费）
2. 左侧「概览」→「创建新扩展」
3. 上传同一个 zip（Edge 兼容 Manifest V3，无需改动）
4. 填写列表信息（文案同上，语言选中文）
5. 隐私声明同 Chrome（Edge 也支持全选「否」）
6. 提交认证 → 通常 1~7 个工作日

## 六、如何截取商店截图

要求：1280×800 或 640×400，PNG/JPEG，1~5 张。

1. 浏览器地址栏打开 `chrome://extensions` → 开发者模式 → 加载已解压的扩展程序 → 选择项目目录
2. 打开一个淘宝商品详情页，把浏览器窗口调到 1280×800（用开发者工具设备模式或系统显示缩放）
3. 截图以下画面：
   - 商品详情页右下角的「获取图片」悬浮按钮
   - 提取后的图库网格页（全选/反选/下载按钮）
   - 下载进度面板
4. 截屏工具：Windows `Win+Shift+S`，或按 F12 → Ctrl+Shift+P → "Capture screenshot"

## 七、版本更新流程

1. 修改代码后更新 `manifest.json` 的 `version` 字段（如 1.0.1）
2. 重新打包：`dist/ecommerce-image-extractor-v1.0.1.zip`
3. 在商店控制台对应项目上传新 zip → 提交审核
